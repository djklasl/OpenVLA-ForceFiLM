# LIBERO 吸盘数据采集操作说明

## 这是什么

这是一个通过浏览器远程操作机械臂的网页采集系统。

你不需要登录服务器，也不需要改代码。你的工作只有一件事：

- 打开负责人发给你的网页地址
- 按页面提示观看原始轨迹
- 在需要的时候接管机械臂
- 完成你被分配到的 task 采集

这个系统采的是 **LIBERO suction（吸盘）版本** 的原始数据。

---

## 你需要做什么

你只负责负责人分配给你的那 5 个 task。

每个 task 下面不止 1 条数据，而是有多条 `demo_x`。
你的目标不是“随便做一条”，而是：

- 把你负责的每个 task 下所有需要采集的 demo 都做完

如果你不确定自己负责哪 5 个 task，直接问负责人，不要自己猜。

---

## 怎么打开页面

负责人会发给你一个网页地址，通常长这样：

```text
http://服务器IP:端口/
```

例如：

```text
http://10.x.x.x:8081/
```

打开以后，请先确认页面顶部这两项都变成“已连接”：

- 控制通道
- 监看通道

如果没有连接成功：

- 先等几秒
- 再刷新页面试一次
- 还是不行就联系负责人

开始操作前，一定先用鼠标点击一下网页，让网页获得键盘焦点。

---

## 页面一共有哪几个阶段

### 1. 任务入口页

你刚进入一个新 task 时，会先看到这个页面。

这个阶段页面通常只有两个按钮：

- `播放原始LIBERO轨迹`
- `退出`

这个阶段的目的只有一个：

- 先看清楚目标物体是谁
- 先看清楚最终应该放到哪里

这个阶段 **不要急着操作机械臂**。

### 2. 原始轨迹预览

点击 `播放原始LIBERO轨迹` 之后，系统会自动播放一遍原始成功示范。

这个阶段：

- 只是看
- 不采数据
- 不需要你操作机械臂

你需要重点观察：

- 要操作的是哪个物体
- 物体最后应该被放到哪里

### 3. 预览完成页

原始轨迹看完以后，会进入这个页面。

这个阶段通常会出现三个按钮：

- `数据采集`
- `重播`
- `退出`

这时你有 3 个选择：

- 如果你已经看懂了，就点 `数据采集`
- 如果你还没看清楚，就点 `重播`
- 如果你现在不想继续，就点 `退出`

### 4. 数据采集中

点击 `数据采集` 后，系统就开始真正采这一条 demo。

这个阶段通常分成两段：

- 前半段：系统自动回放
- 后半段：你人工接管

你需要在合适的时机按 `H`，从自动模式切到人工模式。

## 页面按钮分别是什么意思

### `播放原始LIBERO轨迹`

作用：

- 播放一遍原始成功轨迹
- 让你先看懂目标物体和目标位置

注意：

- 这个按钮 **不会保存数据**

### `数据采集`

作用：

- 开始采当前 task 中下一个未完成的 `demo_x`

注意：

- 点了这个按钮才会进入真实采集流程

### `重播`

作用：

- 再播放一遍原始成功轨迹

适用场景：

- 你还没看清楚目标物体
- 你还没看清楚应该放到哪里
- 你想再确认一次操作过程

注意：

- `重播` **不会保存数据**

### `退出`

作用：

- 结束当前网页采集流程

注意：

- 已经保存到服务器上的数据不会丢失
- 但当前还没保存完成的那一条 demo，不能算成功完成

## 键盘按键分别是什么意思

这些按键主要在 **数据采集中** 使用。

在任务入口页和预览完成页，优先使用页面按钮，不要乱按键盘。

### 方向控制

- `W`：控制机械臂沿一个方向移动
- `S`：控制机械臂沿反方向移动
- `A`：左右移动
- `D`：左右移动
- `↑`：向上
- `↓`：向下

你不用记坐标系，只需要根据画面观察机械臂怎么动。

### 吸盘控制

- `Space`：切换吸盘开 / 关

按一次切换一次：

- 如果当前是关，就会切到开
- 如果当前是开，就会切到关

### 模式切换

- `H`：从自动模式切到人工模式

什么时候按：

- 当你觉得系统自动回放已经接近目标
- 接下来需要你自己精细调整时

### 放弃当前这一条 demo

- `R`：重启当前 demo

这表示：

- 当前这条 demo 作废
- 系统会回到菜单页面
- 你可以重新看预览，或者重新开始采这一条

非常重要：

- 按了 `R`，当前这条 demo **不会保存**

### 退出整个脚本

- `Esc`：退出整个采集流程

只有在你确定自己要结束当前页面时再按。

## 什么时候数据会保存到服务器

这是最重要的部分。

### 会保存的情况

只有当 **一条 `demo_x` 正常采集完成** 时，数据才会真正保存到服务器。

保存时，服务器会做两件事：

1. 把这一条 demo 写进当前 task 对应的 HDF5 文件
2. 立刻把数据刷到磁盘
3. 同时更新这一位工作者自己的 metainfo JSON

你可以把它理解成：

- 只有一整条 demo 结束并成功落盘，才算真的保存

### 不会保存的情况

下面这些情况都 **不会** 产生一条有效保存数据：

- 只看原始轨迹预览
- 点击 `重播`
- 正在操作中，但这条 demo 还没结束
- 按了 `R` 重启当前 demo
- 中途退出，导致当前这条 demo 没正常完成

### 你怎么判断“刚才那条已经保存了”

可以看这几个信号：

- 页面回到了菜单页，或者进入下一条 demo
- 终端那边会打印“已保存 xxx / demo_x”

如果你自己看不到终端，那就按这个原则理解：

- **只有当前这一条 demo 完整结束，并且系统已经回到下一步流程，才能认为它已经保存**

如果你中途按了 `R`，或者还停留在当前采集过程中，就不要认为已经保存。

## 建议的实际操作流程

每做一个新 task，建议按这个顺序来：

1. 先点 `播放原始LIBERO轨迹`
2. 看清楚目标物体和目标位置
3. 如果没看清楚，就点 `重播`
4. 确认后点 `数据采集`
5. 自动阶段接近目标时，按 `H` 切人工
6. 人工完成当前这一条 demo
7. 如果做坏了，按 `R` 重来
8. 如果这一条正常结束，就继续下一条
9. 直到当前 task 下所有 demo 都做完

---

## 常见注意事项

### 1. 一定先点击网页，再按键盘

如果网页没有焦点，你按键盘可能不会生效。

### 2. 不要同时打开多个同一个页面标签页

一个 worker 对应一个网页页面即可。

不要同时开多个相同页面去操作，避免控制混乱。

### 3. 不确定时先重播，不要硬做

如果你没看懂目标物体或目标位置：

- 先点 `重播`
- 不要凭感觉硬做

### 4. 做坏了就按 `R`

如果当前这条 demo 已经明显做坏了：

- 直接按 `R`
- 重新来一条

不要为了“省事”把错误轨迹硬做完。

### 5. 页面断开时不要乱试

如果网页突然断开、卡住、按钮没反应：

- 先截图
- 联系负责人

不要自己频繁刷新、乱开多个页面。

---

## 你最终需要交付什么

你最终要交付的不是“我做过了”，而是：

- 你负责的 5 个 task 全部采完

采完后请通知负责人，由负责人统一做后续合并。

---

## 一句话总结

先看预览，再开始采集；需要时按 `H` 接管，做坏了按 `R` 重来；只有一条 demo 正常结束后，数据才真正保存到服务器。
